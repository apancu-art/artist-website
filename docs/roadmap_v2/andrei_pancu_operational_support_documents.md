# Andrei Pancu — Operational Support Documents

## Inventory Framework
Use one line per work with the following fields:

| Field | Use |
|---|---|
| Inventory ID | Unique code, e.g. AP-PL-2026-001 or AP-PR-2026-001 |
| Work type | Plate, print, video, magnetic construction |
| Title | Full title or Untitled with numbering |
| Year | Year completed |
| Series | Body of work / series name |
| Materials | Full materials line |
| Dimensions | In cm and inches if needed |
| Edition | Unique, AP, or edition number |
| Image file | Master image filename |
| Status | Available, reserved, sold, NFS, archive |
| Price | Current list price |
| Location | Studio, storage, exhibition, collector |
| Notes | Condition, framing, provenance, related plate/print link |

Recommended coding structure: PL for plate, PR for print, VI for video, MG for magnetic construction. Link each print to its originating plate where applicable so the relation between source object and preserved image remains clear.[file:1][file:3][file:5]

## Pricing Notes
Use a consistent ladder rather than ad hoc pricing. Price by work type, scale, complexity, finish, and whether the work is unique or editioned.[file:3]

Suggested internal framework:
- Plates: price according to whether they are source objects, fully resolved exhibition works, or both.
- Archival prints: create edition structures before public release; keep sizes and edition counts consistent within a series.
- Video: use screening, installation, or edition language only when presentation format is fully defined.
- Magnetic constructions: position as experimental works until the form is more publicly established.

General rules:
- Review prices every 6 to 12 months, not work by work.
- Keep institutional and collector pricing aligned across documents.
- Record discounts, donations, and special terms in writing.

## Contact-List Structure
Track contacts in a spreadsheet or CRM with the following columns:

| Field | Use |
|---|---|
| Name | Full name |
| Organization | Gallery, institution, publication, collector, advisor |
| Role | Curator, dealer, writer, collector, technician, etc. |
| City | Primary city |
| Email | Best contact email |
| Phone | Optional |
| Relationship | Warm, cold, met once, ongoing, collector, advisor |
| Last contact date | Most recent outreach or meeting |
| Next action | Follow-up, invite, send portfolio, schedule studio visit |
| Notes | Specific interests, context, introductions |

Segment the list into galleries, curators, artist-run centres, institutions, collectors, writers, and fabricators. Prioritize relationships that match the current presentation of the practice: materially focused, photographically resolved, and institutionally legible.[file:3]
