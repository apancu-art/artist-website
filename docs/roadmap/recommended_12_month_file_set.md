# Recommended 12-Month File Set

## Core guidance set
These four files are the current core guidance set for the next 12 months:

- andrei_pancu_master_launch_packet_v3.md
- updated_artist_statement.md
- updated_bio.md
- updated_project_text.md

## What each file is for
- **Master launch packet v3**: the central strategy document; use this as the main working reference.
- **Updated artist statement**: use for grants, submissions, website adaptation, and statement refinement.
- **Updated bio**: use for bios, website about page, submissions, and press kits.
- **Updated project text**: use for applications, proposals, exhibition pitches, and residency framing.

## What is still useful but secondary
These older files remain useful as supporting material, references, or archive versions, but they are no longer the main set:
- earlier launch packet and master plan versions
- technical plan files
- profile and preference notes
- PDF versions
- roadmap summary CSV

## What is not yet complete
For a truly comprehensive professional package, the following should still be finalized during the sprint:
- submission-ready CV / artist resume
- short bio and long bio in final polished form
- website-ready homepage, about page, and portfolio intro text
- inventory system
- pricing framework
- certificate of authenticity template adapted to your work
- invoice / sales documents adapted to your work
- contact list structure

## Recommendation
Yes, these four are the correct current core set to guide the 12-month sprint. However, they are the conceptual and strategic core, not the complete administrative and submission package.
